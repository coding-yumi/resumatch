# ResuMatch · AI 驱动的职业资产库与简历叙事引擎

> 用你自己的话讲述每段经历，AI 帮你在不同岗位讲出不同的故事。

---

## 产品背景

这个项目源于我自己的求职经历。

起初，我和很多求职者一样，把简历理解成一份需要不断修改的文档。

每投递一个岗位，我都会重新调整经历描述：投产品岗强调数据分析，投运营岗强调流程优化，投 GTM 岗位又要突出销售赋能。久而久之，我发现真正耗费时间的并不是"修改文字"，而是不断思考：

**同一段经历，到底应该如何讲给不同岗位听？**

后来，在利用 AI 重新分析自己的经历时，我意识到一个更本质的问题：

**简历并不是职业经历本身，而只是职业经历的一种表达。**

真正值得长期沉淀的，不应该是一份份不同版本的简历，而应该是一套能够持续积累的 Career Asset Library（职业资产库）。

于是，我重新设计了 ResuMatch。

它不再只是一个 AI 改简历工具，而是一个帮助用户管理职业资产，并自动生成不同职业叙事（Career Narrative）的 AI 平台。

让每段经历不再只是简历中的一段文字，而是被拆解为可复用的职业资产。

---

## 产品最大的迭代

项目最初的定位其实很简单：AI Resume Optimizer。

```
输入：JD
        ↓
输出：优化后的简历
```

但随着不断使用，我发现一个问题：AI 能够很好地优化文字，却无法解决用户真正的困扰。因为 AI 只能优化已经写出来的内容，却无法理解——用户真正做过什么、真正的能力是什么、真正应该强调什么。

于是，我重新设计了整个产品的数据结构。从 **Resume** 变成 **Career Asset Library**。

也就是说，AI 面对的不再是一份静态简历，而是一套不断积累的职业资产。不同岗位，只是从同一套资产里面，生成不同的 Narrative。

这也是整个产品最大的改变。

---

## 核心功能

**Career Asset Library · 职业资产库** — 用户只需用自己的话写下一段完整经历故事（STAR 结构引导），不需要填字段、打标签。AI 会在匹配时自动理解故事中蕴含的能力和成果。

**JD 智能解析** — 粘贴岗位描述，AI 自动提取岗位方向、硬技能、软技能和核心要求，生成结构化画像。

**职业资产匹配** — AI 阅读每段经历故事的全文，理解故事中的能力与成果后，与目标 JD 进行匹配评分（0-100 分），按分数排序输出 Top 3 推荐。

**两步叙事生成** — 改写不再是简单的文字润色。第一步，AI 从故事中提取可复用的职业资产（核心行动、量化成果、能力标签、关键词替换库）；第二步，根据目标岗位的语言风格，从资产中提取最相关的内容生成简历要点。

## 我的思考

### 为什么是 Web App？

做这个项目之前，我考虑过浏览器插件和本地工具两种形态。最终选了 Web App，主要因为三个考量：第一，JD 分散在多个招聘网站，浏览器插件需要逐个适配，维护成本高；第二，匹配结果需要展示评分理由、资产解析和改写对比等结构化信息，一个完整的页面比弹窗合适；第三，Web App 有链接就能用，不用安装，对想法验证阶段来说门槛最低。

### Prompt 设计上的一些取舍

JD 解析时，我最初让 AI 自由发挥，结果输出不可控。后来改为要求纯 JSON、字段严格固定，可靠性大幅提升。

经历改写是我调整最多的部分。我加了一条硬约束——「不得捏造数据」——这是简历场景的底线。代价是改写后的表述可能不如完全放开约束那样"好看"，但这个权衡在我看来是值得的。最新的两次迭代中，我进一步把改写拆成了两步：先让 AI 从故事中提取职业资产，再基于资产生成叙事。多一步解析虽然多一次 API 调用，但生成的简历要点在关键词匹配和岗位适配度上明显更精准。

### 当前局限与下一步

这个产品目前的主要局限有两个。一是评分精度依赖单一模型，同一段 JD 和经历跑两次可能有 5-10 分的波动；二是不支持 PDF 上传，用户需要手动录入经历——这是使用摩擦最大的环节。

如果继续迭代，我会优先引入 PDF 解析能力，让用户直接上传简历自动提取经历故事。同时考虑多轮评分机制——让 AI 评分后追加一轮自检，用少量 Token 换取更高的评估稳定性。

## 本地运行

```bash
git clone https://github.com/coding-yumi/resumatch.git
cd resumatch
pip install -r requirements.txt
```

在 `.streamlit/secrets.toml` 中配置 API Key：

```toml
ZHIPU_API_KEY = "你的智谱 API Key"
```

运行：

```bash
streamlit run app.py
```
